# @core

Esta carpeta agrupa los modulos funcionales del backend.

## Estado actual

- `core.module.js` registra hoy los modulos `health`, `about` y `users`.
- La carpeta `info/` existe, pero todavia no esta conectada en `core.module.js`.

## Nota importante

Todo lo que represente comportamiento de negocio o endpoints de la API deberia entrar aqui antes que en carpetas globales.
